# Identify uncertainty

Start with the decision, not a list of technical risks.

## Ask

- What do we need to decide next?
- What are we assuming in order to make that decision?
- Which assumptions could materially change the outcome?
- Which uncertainties are cheap to resolve now?
- Which uncertainties can safely wait?
