# Turn uncertainty into tests

A useful test connects an important uncertainty to observable evidence.

## A simple pattern

1. State the assumption.
2. Explain why it matters to the decision.
3. Define the smallest useful test.
4. Decide what evidence will be collected.
5. Agree what different results would mean.
