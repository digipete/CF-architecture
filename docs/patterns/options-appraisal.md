# Options appraisal

Compare realistic choices without hiding the trade-offs.

Always consider **do nothing** where it is a genuine option. It establishes the cost and consequence of not changing anything.

## Suggested dimensions

| Dimension | Questions |
| --- | --- |
| Outcome | How well does this support the desired outcome? |
| Cost | What are the whole-life and transition costs? |
| Risk | What could cause harm or failure? |
| Speed | How quickly can we learn or deliver value? |
| Reversibility | How expensive is it to change our mind? |
| Sustainability | Can the partner own and operate it? |
| User impact | What changes for users? |
| Operational impact | What changes for people running the service? |

The result should make trade-offs visible, not manufacture a mathematically precise winner.
